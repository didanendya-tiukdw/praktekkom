      Bagian A · Struktur HTML

      Pengenalan HTML dan persiapan

      HTML (HyperText Markup Language) adalah bahasa markup yang mendeskripsikan struktur dan makna isi halaman web. HTML bukan bahasa pemrograman: tidak ada variabel, percabangan, atau perulangan seperti di bahasa C. HTML bekerja dengan elemen yang ditandai tag; browser membaca dokumen dari atas ke bawah lalu membangun pohon dokumen (DOM). Standarnya dikelola WHATWG sebagai HTML Living Standard (dikenal sebagai HTML5).

      Anatomi elemen

      Klik bagian kode atau tombol di bawahnya untuk melihat nama dan fungsinya.

      Pilih salah satu bagian elemen.

      Aturan dasar penulisan

      Elemen berpasangan dan kosong

      Elemen berpasangan punya tag pembuka dan penutup: <p>...</p>. Elemen kosong (void) tidak punya konten dan penutup: <br>, <hr>, <img>, <input>, <meta>.

      Bersarang (nesting)

      Tutup dengan urutan terbalik. <p><strong>teks</strong></p> benar; <p><strong>teks</p></strong> salah.

      Huruf kecil dan tanda kutip

      Konvensi: nama tag dan atribut huruf kecil, nilai atribut selalu dalam tanda kutip ganda: alt="Logo UKM".

      Spasi diabaikan

      Browser menggabungkan spasi dan baris baru berlebih menjadi satu spasi. Tata letak teks ditentukan elemen, bukan spasi. Komentar ditulis <!-- ... -->.

      Persiapan lingkungan kerja

      Centang setiap langkah setelah selesai. Status centang tersimpan di browser Anda.

      Bagian B · Struktur HTML

      Document structure

      Setiap dokumen HTML5 memiliki kerangka baku yang sama. Klik setiap baris kode di bawah untuk melihat fungsinya.

      Hubungan antarelemen membentuk pohon: elemen di dalam elemen lain adalah anak (child), pembungkusnya induk (parent). Buka tab Pohon DOM pada lab berikut, lalu coba pindahkan <h1> ke dalam <head> dan amati tab Pemeriksaan.

      Catatan penting

      Satu dokumen hanya boleh punya satu <html>, <head>, dan <body>. Elemen yang tampil (heading, paragraf, gambar) tidak boleh di dalam <head>. Jika huruf seperti "é" tampil aneh, periksa <meta charset="UTF-8"> dan pengodean file di VS Code (pojok kanan bawah).

      Bagian C · Struktur HTML

      Elemen semantik

      Elemen semantik namanya menjelaskan peran kontennya: <nav> berarti navigasi, <footer> berarti kaki halaman. <div> dan <span> adalah elemen generik tanpa makna. Manfaatnya: aksesibilitas (screen reader mengenali area halaman sebagai landmark), SEO (mesin pencari memahami konten utama), dan keterbacaan kode.

      ElemenMakna dan penggunaanContoh isi
      <header>Pembuka halaman atau pembuka <article>/<section>Logo, nama situs, judul artikel
      <nav>Kelompok tautan navigasi utamaMenu utama, daftar isi
      <main>Konten utama yang unik; hanya satu per halamanSeluruh isi inti halaman
      <section>Bagian tematik, umumnya diawali heading"Tentang", "Jadwal"
      <article>Konten mandiri yang bermakna jika berdiri sendiriArtikel blog, berita, kartu produk
      <aside>Konten pendukung yang terkait tidak langsungKotak tips, tautan terkait
      <footer>Penutup halaman atau penutup bagianHak cipta, kontak
      <figure> + <figcaption>Ilustrasi mandiri yang dirujuk teks, beserta keterangannyaGambar, diagram, potongan kode

      Teka-teki tata letak

      Pilih elemen semantik yang paling tepat untuk setiap blok kerangka halaman blog berikut, lalu periksa.

      Contoh halaman semantik

      <article> berada di dalam <section>, dan <figure> di dalam <article> karena gambar itu bagian dari artikel. Di tab Pohon DOM, elemen semantik ditandai warna.

      Bagian D · Struktur HTML

      Heading

      Heading <h1>–<h6> menandai struktur dokumen, seperti judul bab dan subbab, bukan ukuran huruf. Pengguna screen reader sering melompat dari heading ke heading. Aturannya:

      1. Satu <h1> per halaman sebagai judul utama.
      2. Jangan melompati tingkat saat turun (h2 → h3, bukan h2 → h4). Naik kembali (h4 → h2) diperbolehkan.
      3. Pilih tingkat berdasarkan posisi dalam struktur; ukuran huruf diatur CSS.
      4. Setiap <section> dan <article> sebaiknya punya heading.

      Penyusun kerangka heading

      Ubah tingkat atau tambah heading. Kerangka di kanan diperbarui langsung, dan pelanggaran aturan ditandai merah.

      Paragraf dan pemformatan teks

      ElemenMakna dan ketentuanTampilan bawaan
      <p>Satu paragraf; tidak boleh berisi elemen blok seperti <ul> atau <table>Blok berjarak
      <br>Pindah baris yang bermakna (alamat, puisi). Bukan untuk jarak antarparagrafBaris baru
      <hr>Pergantian topik (thematic break)Garis horizontal
      <strong>Sangat penting, serius, mendesakTebal
      <em>Penekanan yang mengubah nuansa kalimatMiring
      <blockquote>Kutipan panjang; cite berisi URL sumber. Kutipan pendek: <q>Blok menjorok
      <pre>Teks preformatted; spasi dan baris baru dipertahankanMonospace

      <b> dan <i> masih valid, tetapi hanya untuk teks yang perlu menonjol tanpa tambahan kepentingan (kata kunci, istilah asing). Untuk kepentingan dan penekanan, gunakan <strong> dan <em>.

      Konverter entitas karakter

      Karakter <, >, &, dan " punya arti khusus dalam HTML. Ketik teks atau kode di kiri; versi aman untuk ditulis di dalam HTML muncul di kanan.

      Bagian F · Demonstrasi elemen
      
      
      Hyperlink
      
      
      Hyperlink dibuat dengan <a href="tujuan">teks</a>. Absolute URL berisi alamat lengkap (protokol + domain) untuk situs lain. Relative URL berisi lokasi relatif terhadap file saat ini, untuk halaman dan aset situs sendiri; tetap berfungsi ketika folder dipindah atau dipublikasikan ke GitHub Pages.
      
      
      
        
      BentukKeteranganContoh

      Tautan internalMenuju elemen ber-id di halaman yang sama (huruf besar-kecil dibedakan)#kontak

      Bagian G · Demonstrasi elemen
      
      
      Gambar
      
      
      <img> adalah elemen kosong. src berisi lokasi file; alt wajib ada dan isinya ditentukan oleh fungsi gambar. width dan height (piksel, tanpa satuan) membuat browser menyiapkan ruang sebelum gambar terunduh sehingga halaman tidak "melompat". Format umum: JPEG untuk foto, PNG untuk transparansi, SVG untuk ikon/diagram, WebP sebagai format modern berukuran kecil.
      
      
      Pilih teks alternatif yang tepat
      
      
      
      
      
      
      Contoh gambar dan figure
      
      
      Ubah salah satu nama file pada src menjadi nama yang tidak ada: pratinjau menampilkan teks alt sebagai pengganti. <figcaption> terlihat semua orang, sedangkan alt adalah pengganti gambar; keduanya saling melengkapi.
      
      
      
      
      Hak cipta gambar
      Gambar dari internet tidak otomatis boleh dipakai. Gunakan foto sendiri atau foto berlisensi terbuka (mis. Wikimedia Commons: CC0, CC BY, CC BY-SA). Untuk CC BY/CC BY-SA, cantumkan pembuat, lisensi, dan sumber di dekat gambar, misalnya dalam <figcaption> atau <small>, seperti pada contoh di modul ini.

      Bagian I · Demonstrasi elemen
      
      
      Tabel
      
      
      Tabel hanya untuk data tabular, bukan untuk tata letak. Struktur semantiknya: <table> › <caption> (anak pertama) › <thead>/<tbody>/<tfoot> › <tr> › <th>/<td>. colspan="n" melebarkan sel ke n kolom, rowspan="n" memanjangkan ke n baris; baris di bawah sel rowspan tidak lagi menulis sel di kolom itu. scope="col"/"row" pada <th> membuat screen reader membacakan sel beserta judulnya.
      
      
      Coba
      Di lab berikut, tambahkan satu <td> ekstra pada baris kedua (di bawah sel rowspan). Tab Pemeriksaan menghitung kolom setiap baris dan menandai baris yang tidak konsisten.

      Bagian J · Demonstrasi elemen
      
      
      Formulir
      
      
      <form> membungkus kontrol input; action berisi URL pemroses dan method cara pengirimannya. Setiap kontrol yang datanya dikirim wajib punya name (data dikirim sebagai pasangan name=value) dan label yang terhubung: nilai for pada <label> sama dengan id kontrol. <fieldset> + <legend> mengelompokkan kontrol yang berkaitan.
      
      
      
        
      method="get"
      Data ditambahkan ke URL (query string): terlihat, tersimpan di riwayat, bisa di-bookmark. Untuk pencarian dan penyaringan. Bawaan jika method tidak ditulis.
      
        
      method="post"
      Data dikirim di badan permintaan HTTP. Untuk pendaftaran, login, unggah file, dan data yang mengubah isi server (tetap wajib HTTPS).
      
      
      
      
      Lab formulir dan validasi
      
      
      Isi formulir lalu klik Daftar. Browser memeriksa aturan validasi lebih dulu; jika lolos, panel kanan menampilkan data persis seperti yang akan dikirim (tidak ada data yang benar-benar dikirim ke mana pun). Ubah method, atau aktifkan novalidate untuk melihat apa yang terjadi tanpa validasi browser.

        • Struktur dokumen. <!DOCTYPE html>, <html lang="id">, <head> (metadata: meta charset, viewport, description, <title>) dan <body> (konten tampil) membentuk pohon DOM.
          • 
        
        • Semantik. header, nav, main, section, article, aside, footer, figure, figcaption menjelaskan peran konten; div/span hanya bila tak ada yang sesuai.
          • 
        
        • Heading. Satu h1; h2–h6 tanpa melompat tingkat.
          • 
        
        • Teks. p, br, hr, strong, em, blockquote, pre, code; karakter khusus ditulis dengan entitas.
          • 
        
        • Hyperlink. Absolut, relatif (../), #id, mailto:, tel:; target="_blank" + rel="noopener noreferrer".
          • 
        
        • Gambar. src + alt sesuai fungsi (alt="" untuk dekoratif) + width/height; berketerangan dengan figure.
          • 
        
        • List. ul, ol (type, start, reversed), dl; nested list di dalam li.
          • 
        
        • Tabel. Hanya data tabular; caption, thead, tbody, tfoot, th scope; jumlah kolom tiap baris konsisten.
          • 
        
        • Formulir. name + label for=id; fieldset/legend; validasi bawaan membantu pengguna, validasi server tetap wajib.
          • 
        
        • Berbasis spesifikasi. Uraikan → kerangka → isi bertahap → verifikasi + W3C Validator.
