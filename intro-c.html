      Bagian A · menit 05–20

      Lingkungan C: compiler, GCC, dan VS Code

      Bahasa C dikembangkan Dennis Ritchie di Bell Labs pada 1972. Bahasa ini masih dipakai untuk sistem operasi dan perangkat tertanam karena cepat, sederhana, dan portabel. Berbeda dengan Scratch yang langsung berjalan, kode C harus diterjemahkan dulu ke kode mesin oleh compiler.

      Empat tahap di balik gcc

      Animasi di bagian atas halaman menunjukkan alurnya. Pilih tahap untuk melihat contoh isi file yang dihasilkan dari halo.c.

      Siklus kerja di VS Code

      Editor untuk menulis, terminal (Ctrl + `) untuk kompilasi dan menjalankan. Siklusnya selalu: tulis → simpan (Ctrl+S) → kompilasi → jalankan. Jika kompilasi gagal, baca pesan error, perbaiki, simpan, kompilasi ulang.

      Perhatian

      Lupa menyimpan atau lupa kompilasi ulang adalah penyebab paling umum "program saya tidak berubah". Titik putih di tab editor berarti file belum disimpan.

      Bagian B · menit 20–30

      Struktur program C

      Setiap program C punya kerangka yang sama. Arahkan kursor (atau ketuk) baris kode atau kartu penjelasan untuk melihat pasangannya.

      • C bersifat case sensitive: main, Main, dan MAIN berbeda.
      • Statement diakhiri ;. Baris #include dan pembuka blok { tidak.
      • String memakai kutip ganda "...", satu karakter memakai kutip tunggal 'A'.

      Membaca pesan error

      Format pesan GCC: file:baris:kolom: error: penjelasan. Perbaiki mulai dari error pertama.

      Bagian C · menit 30–45

      Variabel dan tipe data

      Variabel adalah nama untuk lokasi di memori. Bayangkan kotak berlabel: label = nama, isi = nilai, ukuran kotak = tipe data. C mewajibkan setiap variabel dideklarasikan beserta tipenya agar compiler tahu berapa byte yang disiapkan.

      Lab memori 3D

      Setiap kubus adalah satu byte. Angka di kubus adalah isi byte dalam heksadesimal (urutan little-endian, seperti di laptop Intel/AMD). Ubah tipe, nama, atau nilai; kode dan output di bawahnya ikut berubah. Seret untuk memutar.

      Visualisasi 3D tidak dapat dimuat. Tabel variabel dan output di bawah tetap berfungsi.
      TipeNamaNilai

      Penyederhanaan: compiler sebenarnya dapat menambahkan padding agar alamat sejajar, dan urutan variabel di memori bisa berbeda.

      Bagian D · menit 45–60

      Operator

      Operator adalah simbol yang memerintahkan operasi pada nilai (operand). Hasil operator relasional dan logika di C berupa bilangan: 1 = benar, 0 = salah.

      Playground operator

      Masukkan dua bilangan bulat. Semua hasil dihitung dengan aturan int 32-bit seperti di C.

      Urutan prioritas

      ( ) → ++ -- ! (cast) → * / % → + - → < > <= >= → == != → && → || → = += -= …

      BentukNamaPerilakuContoh (i = 5)
      i++Post-incrementNilai lama dipakai dulu, lalu i +1j = i++; → j = 5, i = 6
      ++iPre-incrementi +1 dulu, lalu nilainya dipakaij = ++i; → j = 6, i = 6
      Jebakan umum

      = adalah penugasan, == adalah perbandingan. Ekspresi a > b > c tidak bermakna seperti matematika; tulis (a > b) && (b > c).

      LATIHAN6

      Kalkulator nilai akhir mahasiswa

      10 menit · file nilai_akhir.c · Tujuan: memadukan variabel, tipe data, operator, dan I/O.

      Program menerima nama (satu kata) serta nilai Tugas, UTS, UAS. Nilai akhir = 30% Tugas + 30% UTS + 40% UAS. Status lulus (nilai akhir ≥ 60) ditampilkan sebagai 1 = ya, 0 = tidak.

      Input

      char nama[50]
      float tugas, uts, uas

      Proses

      akhir = 0.3·tugas + 0.3·uts + 0.4·uas
      lulus = akhir >= 60

      Output

      Nama, nilai akhir (2 desimal), status 1/0
      1. Deklarasikan variabel sesuai tabel IPO.
      2. Tulis input: 4 pasang printf + scanf.
      3. Hitung akhir dan simpan akhir >= 60 ke int lulus.
      4. Uji dengan (Dida, 80, 75, 90) dan (Budi, 50, 55, 60).
      Kunci jawaban Latihan 6

      Dida: 24 + 22,5 + 36 = 82,50 (lulus 1). Budi: 15 + 16,5 + 24 = 55,50 (lulus 0). Pada Pertemuan 22, if-else akan mengubah 1/0 menjadi teks "LULUS"/"TIDAK LULUS".

      Bagian 3

      Rangkuman

      • GCC dipasang lewat MSYS2: installer → terminal UCRT64 → pacman -S mingw-w64-ucrt-x86_64-gcc → tambahkan C:\msys64\ucrt64\bin ke PATH.
      • Program C harus dikompilasi: preprocessing → compilation → assembly → linking, menghasilkan .exe.
      • Siklus: tulis → simpan → gcc -Wall file.c -o file → .\file. Setiap perubahan butuh kompilasi ulang.
      • Struktur: #include, main(), blok { }, statement diakhiri ;, komentar, return 0;.
      • Tipe dasar: char 1 byte, int 4, float 4, double 8; string adalah array char.
      • Pembagian dua bilangan bulat menghasilkan bilangan bulat; pakai literal desimal atau casting.
      • Relasional dan logika menghasilkan 1 (benar) atau 0 (salah).
      • scanf perlu & kecuali string; double dibaca dengan %lf.
