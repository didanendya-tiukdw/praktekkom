Panduan Praktikum Web

Perangkat yang Dibutuhkan

  • Visual Studio Code
  • Web browser (Chrome, Firefox, atau Edge)
  • Akun GitHub

Langkah Membuat Halaman

  1. Buat folder proyek.
  2. Buat file index.html.
  3. Tulis struktur dasar HTML5.
  4. Buka file di browser.

Tahapan Lanjutan

  1. Validasi kode di W3C Validator.
  2. Commit ke repositori Git.

Glosarium

HTML
HyperText Markup Language, bahasa markup untuk struktur halaman web.
Tag
Penanda elemen yang ditulis di antara tanda < dan >.
