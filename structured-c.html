      Bagian A · menit 05–25
      
      
      Percabangan
      
      
      Percabangan membuat program mengambil keputusan. Kondisinya adalah ekspresi relasional atau logika yang bernilai 1 (benar) atau 0 (salah), seperti operator di P10.
      
      
      
        
      BentukSintaksDipakai ketika
      
        
          
      ifif (kondisi) { ... }Aksi tambahan hanya jika kondisi benar
      
          
      if-elseif (k) { ... } else { ... }Dua kemungkinan, tepat satu dijalankan
      
          
      else ifif (k1) {...} else if (k2) {...} else {...}Lebih dari dua kemungkinan berupa rentang
      
          
      switchswitch (x) { case 1: ... break; default: ... }Memilih berdasarkan nilai tepat (int/char)
      
          
      ternaryv = (k) ? a : b;Memilih satu dari dua nilai dalam satu baris
      
        
      

      
      Penjelajah else-if
      
      
      Geser nilai dan amati: kondisi diperiksa dari atas, dan pemeriksaan berhenti di kondisi pertama yang benar. Karena itu nilai >= 70 tidak perlu ditulis nilai >= 70 && nilai < 85.
      
      
      
      
      Hasil
      B
      
      
      

      
      Kondisi majemuk
      
      
      Tahun kabisat: habis dibagi 4 dan tidak habis dibagi 100, atau habis dibagi 400. Coba 2024, 1900, dan 2000.
      
      
      

      
      switch dan ternary
      
      
      Setiap case diakhiri break. Tanpa break, eksekusi jatuh (fall through) ke case berikutnya. Case 6 dan 7 di bawah sengaja digabung memakai sifat ini.
      
      
      
      
      Jebakan
      if (x = 5) menyimpan 5 ke x sehingga kondisi selalu benar; gunakan ==. Titik koma setelah kondisi, if (x > 0);, membuat if tidak mengatur apa pun.
      

      
      
        
      LATIHAN1
      
          
      Kalkulator dengan switch
      ± 8 menit · file kalkulator.c · Tujuan: memilih aksi dengan switch dan menangani kasus khusus dengan if.
      
        
      
          
      Program membaca ekspresi seperti 12 / 5 dan menampilkan hasil 2 desimal untuk operator + - * /. Pembagian dengan nol ditolak, operator lain dinyatakan tidak dikenal.
      
          
      1. Lengkapi TODO 1: case - dan *.
      2. TODO 2: pada case /, tolak b == 0 dengan if.
      3. TODO 3: default mencetak Operator '?' tidak dikenal.
      4. Uji: 12 / 5, 7 * 3, 9 / 0, 4 % 2.
      
          
      
          
      Kunci jawaban Latihan 1
      Ketik ekspresi lain di kolom kuning untuk menguji kunci.
      
        
      
      
      
    
      

    
    
      
      
      Bagian B · menit 25–45
      
      
      Perulangan
      
      
      Perbedaan utama ketiga perulangan adalah kapan kondisi diperiksa.
      
      
      JenisKondisi diperiksaMinimal jalanPaling cocok untuk
      
        
      forAwal0 kaliJumlah ulangan diketahui (1 sampai n, indeks array)
      
        
      whileAwal0 kaliUlangi selama syarat terpenuhi (memproses digit)
      
        
      do-whileAkhir1 kaliMenu dan validasi input
      
      
      
      
      for: pola akumulator
      
      
      

      
      while dan tabel tracing
      
      
      Tabel tracing mencatat nilai setiap variabel per putaran; teknik ini sangat berguna saat troubleshooting. Ubah angka lalu tekan Putaran berikutnya.
      
      
      
      
      
      
      Putaranangka (awal)digit = angka % 10balik = balik*10 + digitangka = angka / 10angka > 0 ?
      

      
      do-while untuk validasi input
      
      
      Masukkan beberapa input berurutan (pisahkan dengan spasi). Program terus meminta ulang sampai nilainya 0–100.
      
      
      

      
      break, continue, dan perulangan bersarang
      
      
      
      
      Perhatian
      Infinite loop terjadi jika kondisi tidak pernah salah, misalnya lupa i++; hentikan dengan Ctrl+C. Off-by-one: i <= n versus i < n menentukan apakah putaran terakhir dijalankan.
      

      
      Tebak output
      
      
      Tulis tebakan Anda, lalu periksa.
      
      
      
      
      

      
      
        
      LATIHAN2
      
          
      Tabel perkalian
      ± 8 menit · file perkalian.c · Tujuan: perulangan bersarang dan format lebar printf.
      
        
      
          
      A. Baca n, cetak tabel perkalian n × n dengan printf("%4d", i * j). B. Hitung berapa hasil kali yang genap dan tampilkan di bawah tabel. Untuk n = 5, tebak dulu jumlahnya sebelum menjalankan.
      
          
      1. Loop luar i = baris, loop dalam j = kolom.
      2. Cetak \n setelah loop dalam selesai.
      3. Bagian B: if ((i * j) % 2 == 0) genap++;
      
          
      Kunci jawaban Latihan 2
      
            
      Hasil kali ganjil hanya jika kedua faktor ganjil. Untuk n = 5 ada 3 bilangan ganjil, jadi 3 × 3 = 9 hasil ganjil dan 25 − 9 = 16 hasil genap.
      
        
      
      
      
    
      

    
    
      
      
      Bagian C · menit 45–65
      
      
      Fungsi
      
      
      Fungsi adalah kotak hitam: menerima masukan, memprosesnya, lalu menghasilkan keluaran. Fungsi membuat program terorganisasi, mudah diuji, dan dapat dipakai ulang.
      
      
      IstilahContohKeterangan
      
        
      Prototypeint kuadrat(int x);Ditulis sebelum main agar compiler mengenal fungsi yang didefinisikan di bawah
      
        
      Definisiint kuadrat(int x) { return x * x; }Isi fungsi
      
        
      Pemanggilankuadrat(3)Argumen 3 disalin ke parameter x
      
        
      returnreturn x * x;Mengirim hasil ke pemanggil
      
        
      voidvoid garis(int panjang)Tidak mengembalikan nilai, hanya melakukan aksi
      
      
      
      
      Ubah argumen di kolom kuning; hasil tiap pemanggilan ikut berubah.
      
      
      
      
      Pass by value dan scope
      
      
      Argumen dikirim sebagai salinan. Mengubah x di dalam fungsi tidak mengubah nilai di main. Variabel di dalam fungsi bersifat lokal; yang dideklarasikan di luar semua fungsi bersifat global.
      
      
      
      
      Tips
      Kirim data lewat parameter dan return, bukan variabel global, agar alur data jelas dan fungsi mudah diuji.

      Tiga sisi membentuk segitiga jika semua positif dan jumlah dua sisi mana pun lebih besar dari sisi ketiga. Buat bool validSegitiga(float a, float b, float c) dan void cetakJenis(float a, float b, float c) (sama sisi, sama kaki, sembarang).
      
          
      
          
      UjiInputOutput yang diharapkan

      35 5 8Segitiga valid · Jenis: sama kaki
      41 2 3Bukan segitiga
      5-3 4 5Bukan segitiga
      
          
      Kunci jawaban Latihan 3
      
            
      (1, 2, 3) bukan segitiga karena 1 + 2 = 3 tidak lebih besar dari 3. Membandingkan float dengan == aman untuk input bilangan bulat; untuk hasil perhitungan desimal, bandingkan selisihnya dengan toleransi kecil.
      
        
      
      
      
    
      

    
    
      
      
      Bagian D · menit 65–85
      
      
      Array
      
      
      Array menyimpan data bertipe sama di memori yang berurutan. Indeks dimulai dari 0 sampai n − 1. Jumlah elemen dihitung dengan sizeof(arr) / sizeof(arr[0]). Ubah isi array di kolom kuning.
      
      
      
      
      Pencarian linear
      
      
      
      
      Mengirim array ke fungsi
      
      
      Array tidak disalin saat dikirim ke fungsi: fungsi bekerja pada array asli. Karena fungsi tidak tahu ukurannya, kirim juga n. Bandingkan dengan scope.c di Bagian C.
      
      
      

      
      Lab array 2 dimensi 3D
      
      
      Setiap kubus adalah satu elemen m[r][c]. Pilih urutan perulangan lalu tekan Telusuri untuk melihat urutan kunjungan dan output-nya. Di memori, elemen 2D tetap disimpan berderet baris demi baris (row-major), sehingga alamatnya &m[0][0] + (r × kolom + c) × 4. Seret untuk memutar.
      
      
      
        
      Visualisasi 3D tidak dapat dimuat. Kode dan output di samping tetap berfungsi.
      
        
      
          
      matriks.c
      
          
      
          
      
          
      
        
      
      
      
      
      
        
        
        
        
        
        
      
      
      
      Perhatian
      C tidak memeriksa batas array. nilai[5] pada array berukuran 5 tidak menimbulkan error kompilasi tetapi membaca memori lain. Gunakan i < n, bukan i <= n.
      

      
      
        
      LATIHAN4
      
          
      Statistik nilai kelas (problem solving)
      ± 12 menit · file statistik.c · Tujuan: memadukan perulangan, percabangan, fungsi, dan array.
      
        
      
          
      Program membaca jumlah mahasiswa n (1–50, minta ulang jika di luar rentang), lalu n nilai bulat, dan menampilkan rata-rata, nilai tertinggi, terendah, serta jumlah yang lulus (≥ 60).
      
          
      
            
      Input
      int n (1–50)
      int nilai[50]
      
            
      Fungsi
      double rataRata(int arr[], int n)
      int nilaiMaks(...), int nilaiMin(...)
      int hitungLulus(int arr[], int n, int batas)
      
            
      Output
      Rata-rata (2 desimal), tertinggi, terendah, jumlah lulus
      
          
      
          
      1. Tulis empat prototype di atas main.
      2. Validasi n dengan do-while; isi array dengan for + scanf("%d", &nilai[i]).
      3. Maks/min: mulai dari arr[0], bandingkan mulai indeks 1.
      4. Rata-rata: (double) total / n.
      5. Uji: n = 6, nilai 78 92 55 64 88 47. Hitung manual dulu.
      
          
      Kunci jawaban Latihan 4
      
            
      Manual: total 424, rata-rata 424 / 6 = 70,666… → 70.67, tertinggi 92, terendah 47, lulus 4.
      
        
      
      
      
    
      

    
    
      
      
      Bagian E · menit 85–95
      
      
      Troubleshooting terbimbing
      
      
      Error sintaks ditolak compiler dan pesannya menunjuk baris. Error logika lolos kompilasi tetapi hasilnya salah; inilah yang paling sering muncul pada percabangan, perulangan, dan array.
      
      
      
        
      1. Kompilasi dengan warning
      gcc -Wall -Wextra, baca pesan pertama, lihat juga baris sebelumnya.
      
        
      2. Telusuri
      Cetak nilai variabel penting (printf("[debug] ...")) atau isi tabel tracing untuk input kecil.
      
        
      3. Perbaiki satu hal
      Ubah satu hal, kompilasi, uji kasus normal dan kasus batas (0, 1, n maksimum).

      Bagian 3
      
      
      Rangkuman
      
      
        
        
      • Percabangan: if, if-else, else if (berhenti di kondisi benar pertama), switch (jangan lupa break), ternary ?:.
        • 
        
      • Perulangan: for (jumlah ulangan diketahui), while (cek di awal), do-while (minimal sekali). break menghentikan, continue melompat.
        • 
        
      • Pola penting: akumulator, penghitung, pencarian dengan penanda -1, maks/min mulai dari elemen pertama.
        • 
        
      • Fungsi: tipe kembalian, nama, parameter, badan; prototype sebelum main; argumen dikirim by value; variabel di dalam fungsi bersifat lokal.
        • 
        
      • Array: indeks 0 sampai n − 1; dikirim ke fungsi tanpa disalin, jadi kirim juga ukurannya; array 2D disimpan baris demi baris.
        • 
        
      • Troubleshooting: -Wall -Wextra, baca warning, telusuri dengan printf atau tabel tracing, perbaiki satu hal setiap kali.
